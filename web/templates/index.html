Help & Documentation

Format Conversion

Convert between multiple EDA data formats:

  • AIG to BENCH: And-Inverter Graph to BENCH netlist
  • BENCH to GraphML: BENCH netlist to GraphML format
  • GraphML to PyTorch: GraphML to PyTorch Geometric format
  • Verilog to AIG: Verilog HDL to AIG format
  • AIG to PyTorch (Direct): One-step AIG to PyTorch conversion
  • Verilog to PyTorch (Direct): One-step Verilog to PyTorch conversion

Metrics Analysis

Calculate area and delay metrics for digital circuits:

  • Supports AIG and BENCH file formats
  • Uses Liberty library files (.lib) for accurate metrics
  • Powered by Berkeley ABC synthesis tool
  • Batch processing support for multiple files

AI Code Analysis

Analyze Verilog code with AI-powered insights:

  • Upload Verilog (.v, .sv) files for analysis
  • Ask specific questions about your code
  • Get explanations, bug detection, and optimization suggestions
  • Powered by DeepSeek AI

CLI Usage

Use the command-line interface for batch processing and automation:

Basic Command Structure

ai4eda <command> <subcommand> [options]

Format Conversion Examples

AIG to BENCH:

ai4eda convert aig2bench input.aig output.bench

BENCH to GraphML:

ai4eda convert bench2graphml input.bench output.graphml

GraphML to PyTorch:

ai4eda convert graphml2pt input.graphml output.pt

Verilog to AIG:

ai4eda convert verilog2aig input.v output.aig --top-module my_module

Direct Conversions (One-Step):

ai4eda convert aig2pt input.aig output.pt ai4eda convert verilog2pt input.v output.pt --top-module my_module

Batch Processing

ai4eda convert aig2bench input_dir/ output_dir/ --batch --recursive

Metrics Calculation

ai4eda metrics input.aig --lib libs/asap7.lib ai4eda metrics input.aig --lib libs/asap7.lib --opt-script "balance; rewrite"

Batch metrics:

ai4eda metrics input_dir/ --lib libs/asap7.lib --batch

Python API

Import and use converters in your Python code:

from ai4eda.converters import *

Example Usage

from ai4eda.converters.aig_to_bench import AigToBenchConverter converter = AigToBenchConverter() converter.convert('input.aig', 'output.bench')
